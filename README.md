# Adaptive Map Task

Проект, выполненный для испытания по переводам, 3 курс

## Описание
Проект содержит реализацию структуры данных **Словарь**, динамически меняющей внутреннее представление в зависимости от количества хранимых элементов:

- `0` элементов — значение `None`.
- `1` элемент — ссылка на пару «ключ-значение».
- от `2` до `5` элементов — массив размера 5 с парами.
- более `5` элементов — стандартный словарь `dict`.

### Поддерживаемые методы:
- `put(key, value)` — добавление пары или обновление существующего значения по ключу.
- `contains_key(key)` — проверка наличия ключа в словаре.
- `get(key)` — получение значения по ключу (выбрасывает `KeyError`, если ключ отсутствует).

Поддерживается работа с ключами произвольного типа (числа, строки, кортежи и др.).
